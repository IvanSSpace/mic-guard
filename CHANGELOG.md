# Changelog

## 2026-08-20

### Исправлено
- **Критический баг**: тул вступал в борьбу с системным call-роутингом. Во время звонков (Telegram, FaceTime и т.п.) macOS сама временно (transient) переключает вход на Bluetooth-гарнитуру и корректно откатывает после звонка — штатный механизм. MicGuard не отличал это от обычного грэба и форсил откат обратно за миллисекунды, из-за чего ломался Bluetooth-профиль (HFP/A2DP) — рвался не только вход, но и выход (общий радиоканал), чинилось только переподключением наушников вручную. Теперь: 3+ отката за 5 секунд читаются как борьба с активным звонком — тул отступает на 25 секунд.

## 2026-08-19

### Добавлено
- Первый релиз: menu bar утилита, блокирует Bluetooth-микрофон от захвата default input
- Список приоритета входов с ручным ранжированием (кнопки ↑/↓)
- Чекбокс на устройство — временно исключить его без физического отключения
- Физически отключённые устройства остаются видны в списке (возвращаются на свою позицию при подключении)
- Виртуальные/неопознанные устройства (Loopback, Screaming Bee, Zoom, Teams Audio) сворачиваются в отдельную секцию

### Исправлено
- Виртуальные устройства блокировали выбор реальных физических микрофонов, стоя выше них в общем списке приоритета — теперь исключены из выбора входа полностью
- Кнопки ↑/↓ переставляли устройство с соседом по полному списку, а не по видимому — теперь перестановка только внутри своей категории (физические / виртуальные)
- Подпись «вернётся сам при подключении» показывалась у каждого отключённого устройства — теперь только у топ-1 по рангу, и только если топ-1 сам не подключён
- Реордер и запись приоритета работали на транзитном `AudioDeviceID` — переехали на persistent device UID, переживает переподключение

### Изменено
- Иконка в menu bar: `MenuBarExtra` принудительно рендерит label монохромным вне зависимости от стиля — заменена на кастомный `NSStatusItem`
- Popover с системной стрелкой (arrow) заменён на плоскую панель без неё, выровненную по левому краю кнопки
- Панель плавно гаснет при закрытии вместо мгновенного исчезновения
